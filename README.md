# bugdeck

Open-source Marker.io / BugHerd alternative — self-hosted bug reports with screenshot, annotation
and element picker. Files into Plane, GitHub, Linear.

Packages in this monorepo:

| Package | What it is |
|---------|------------|
| `@bugdeck/core` | Pure core: report contract, block parsing, image sanitisation, issue rendering. |
| `@bugdeck/server` | HTTP API that stores reports and files them into a tracker. |
| `bugdeck` | React widget users click to file a report. |

Quick start, comparison table and screenshots land with the first release.
